Đăng nhập

Mã truy cập là một GitHub token. Token chỉ lưu trên trình duyệt này.

Cài đặt kho (thường không cần đổi)

  1. Vào GitHub → Fine-grained token.
  2. Repository access: Only select repositories → chọn repo của thiệp.
  3. Permissions → Repository → Contents: Read and write.
  4. Tạo token, dán vào ô trên.
